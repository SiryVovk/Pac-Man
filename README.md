Pac-Man (Unity, PC)
A small but complete Pac-Man clone built as part of a 20-game challenge.
The project focuses on clean gameplay architecture, state-driven enemy AI, and basic progression systems.

Key Features:

Custom level system with 4 handcrafted maps, managed through a grid-based Field generator.

Enemy AI built on simple but clear state logic (scatter, chase, frightened).

Event-driven architecture for interactions between player, pellets, ghosts, UI, and game manager.

Basic progression system (level selection, completed level tracking, save system).

Autosave on exit during a level, allowing the player to continue from the exact point they stopped.

Simple PC-focused UI with level select, gameplay HUD, and pause menu.

Clean and readable C# code structure, split into small systems (player movement, tile logic, ghost logic, game/session management).

Not included:
No build uploaded (I can generate one on request), but the full Unity project is available.
